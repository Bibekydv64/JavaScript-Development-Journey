JAVASCRIPT DOM MANIPULATION — LEARNING ROADMAP
===============================================

Goal:
Learn DOM manipulation from fundamentals to advanced topics through one concept
at a time, with reasoning questions and practical exercises.

Learning rule:
1. Study ONE concept at a time.
2. Understand what problem the concept solves and how it works.
3. Write a small example yourself.
4. Answer the reasoning questions.
5. Review mistakes before moving to the next concept.
6. Do not memorize methods without understanding their purpose.

FIRST LESSON — DOM BASICS
-------------------------
Example HTML:

<html>
  <body>
    <h1 id="title">Hello Bhai</h1>
    <button>Click Me</button>
  </body>
</html>

Concept:
The browser parses HTML and creates a tree of objects called the DOM.
JavaScript can select those objects, read or change their content, create
new elements, remove elements, and respond to events.

Reasoning questions:
1. What does DOM stand for?
2. Why does the browser create a DOM tree?
3. Is the DOM the same thing as the original HTML file? Explain.
4. What can JavaScript do through the DOM?
5. If JavaScript changes an element's text, does it permanently rewrite
   the original HTML file on your computer? Why or why not?
