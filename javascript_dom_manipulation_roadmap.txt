JAVASCRIPT DOM MANIPULATION — COMPLETE ROADMAP
===============================================

GOAL:
Learn DOM manipulation from fundamentals to advanced topics.
Understand what each concept means, why it exists, and how to use it.

LEARNING RULE:
1. Study ONE concept at a time.
2. Understand its definition.
3. Understand its purpose.
4. Learn how it works internally.
5. Write a small example yourself.
6. Answer reasoning questions.
7. Review mistakes before moving forward.


PHASE 1 — DOM FUNDAMENTALS
===========================

1. What is DOM (Document Object Model)?
   Definition: A tree-like representation of an HTML webpage.
   Purpose: Allows JavaScript to access and manipulate webpage elements.

2. How browser converts HTML into a DOM tree
   Definition: Browser parses HTML and creates objects from its structure.
   Purpose: Makes HTML structure accessible to JavaScript.

3. The document object
   Definition: JavaScript object representing the webpage document.
   Purpose: Provides access to webpage elements.

4. getElementById()
   Definition: Finds an element using its ID.
   Purpose: Access one specific element quickly.

5. getElementsByClassName()
   Definition: Finds elements using their class name.
   Purpose: Access multiple elements sharing the same class.

6. getElementsByTagName()
   Definition: Finds elements using their HTML tag name.
   Purpose: Select elements such as all paragraphs or buttons.

7. querySelector()
   Definition: Finds the first element matching a CSS selector.
   Purpose: Select elements using CSS selector syntax.

8. querySelectorAll()
   Definition: Finds all elements matching a CSS selector.
   Purpose: Select multiple elements at once.

9. HTMLCollection vs NodeList
   Definition: Two different types of collections containing DOM elements/nodes.
   Purpose: Understand what different DOM selection methods return.

10. Live vs Static Collections
    Definition: Live collections update when DOM changes; static collections
    preserve the original selection.
    Purpose: Understand how collections behave when elements are added or removed.


PHASE 2 — READING AND CHANGING ELEMENTS
========================================

11. innerHTML
    Definition: Gets or changes HTML markup inside an element.
    Purpose: Insert HTML structures dynamically.

12. innerText
    Definition: Gets or changes the rendered text of an element.
    Purpose: Work with text as it is displayed on the webpage.

13. textContent
    Definition: Gets or changes the text content of an element.
    Purpose: Read or display plain text safely without interpreting HTML.

14. value (Form Inputs)
    Definition: Gets or changes the current value of an input.
    Purpose: Read what users type into forms.

15. getAttribute()
    Definition: Gets the value of an HTML attribute.
    Purpose: Read attributes such as href, src, and type.

16. setAttribute()
    Definition: Adds or changes an HTML attribute.
    Purpose: Update element attributes dynamically.

17. hasAttribute()
    Definition: Checks whether an attribute exists.
    Purpose: Verify an element's attributes before performing an action.

18. removeAttribute()
    Definition: Removes an HTML attribute.
    Purpose: Remove attributes such as disabled or readonly.

19. style Property
    Definition: Accesses an element's inline CSS styles.
    Purpose: Change an element's appearance using JavaScript.

20. classList.add()
    Definition: Adds a CSS class to an element.
    Purpose: Apply predefined CSS styling dynamically.

21. classList.remove()
    Definition: Removes a CSS class.
    Purpose: Remove unwanted styling or states.

22. classList.toggle()
    Definition: Adds a class if absent or removes it if present.
    Purpose: Switch between two UI states.

23. classList.contains()
    Definition: Checks whether an element contains a CSS class.
    Purpose: Check the current styling or state of an element.


PHASE 3 — CREATING AND REMOVING ELEMENTS
=========================================

24. document.createElement()
    Definition: Creates a new HTML element.
    Purpose: Build new webpage elements dynamically.

25. document.createTextNode()
    Definition: Creates a text node.
    Purpose: Add plain text as a DOM node.

26. append()
    Definition: Adds nodes or text at the end of an element.
    Purpose: Insert new content inside an element.

27. appendChild()
    Definition: Adds a node as the last child of another node.
    Purpose: Insert a created DOM element into the webpage.

28. prepend()
    Definition: Adds nodes or text at the beginning.
    Purpose: Insert new content before existing children.

29. before() and after()
    Definition: Insert content before or after an element.
    Purpose: Position elements beside existing elements.

30. remove()
    Definition: Removes an element from the DOM.
    Purpose: Delete unwanted webpage elements.

31. replaceWith()
    Definition: Replaces an element with another node or text.
    Purpose: Replace old content with new content.

32. cloneNode()
    Definition: Creates a copy of an existing DOM node.
    Purpose: Reuse an element's structure.

33. Building Dynamic HTML from JavaScript Data
    Definition: Generate webpage elements using arrays and objects.
    Purpose: Display changing data such as products and transactions.


PHASE 4 — DOM EVENTS
=====================

34. What is an Event?
    Definition: An action such as clicking, typing, or submitting a form.
    Purpose: Make webpages respond to user interactions.

35. addEventListener()
    Definition: Registers a function to respond to an event.
    Purpose: Connect user actions with JavaScript functionality.

36. Click Event
    Definition: Event triggered when an element is clicked.
    Purpose: Handle buttons such as Add, Delete, and Save.

37. Input Event
    Definition: Event triggered when an input value changes during editing.
    Purpose: React while users type.

38. Change Event
    Definition: Event triggered when a form control's value is committed.
    Purpose: Detect changed input or selection values.

39. Submit Event
    Definition: Event triggered when a form is submitted.
    Purpose: Handle and validate form data.

40. keydown and keyup
    Definition: Events triggered when keyboard keys are pressed and released.
    Purpose: Handle keyboard interactions and shortcuts.

41. The Event Object
    Definition: An object containing information about an event.
    Purpose: Understand what happened and which elements were involved.

42. event.target and event.currentTarget
    Definition: target is the original event target; currentTarget is the
    element whose listener is currently executing.
    Purpose: Identify the clicked element and the listener's element.

43. preventDefault()
    Definition: Prevents the browser's default action.
    Purpose: Control form submission and other default browser behaviors.

44. stopPropagation()
    Definition: Stops an event from continuing through its propagation path.
    Purpose: Prevent unwanted parent or ancestor event handling.

45. Event Bubbling
    Definition: Events travel from the target element toward its ancestors.
    Purpose: Understand how events move through the DOM.

46. Event Capturing
    Definition: Events travel from ancestors toward the target element.
    Purpose: Handle events during the capturing phase.

47. Event Delegation
    Definition: Uses one parent listener to handle events from child elements.
    Purpose: Handle many dynamic elements efficiently.

48. Removing Event Listeners
    Definition: Removes a previously registered event listener.
    Purpose: Prevent unnecessary event handling.


PHASE 5 — DOM TRAVERSAL
========================

49. parentElement
    Definition: Returns the parent HTML element.
    Purpose: Move from a child to its parent.

50. children
    Definition: Returns the direct child elements.
    Purpose: Access elements inside a container.

51. childNodes
    Definition: Returns all child nodes, including text and comments.
    Purpose: Inspect every child node.

52. firstElementChild and lastElementChild
    Definition: Return the first and last child elements.
    Purpose: Access the first or last element inside a container.

53. nextElementSibling
    Definition: Returns the next sibling element.
    Purpose: Move to the next neighboring element.

54. previousElementSibling
    Definition: Returns the previous sibling element.
    Purpose: Move to the previous neighboring element.

55. closest()
    Definition: Finds the nearest matching element, including the element itself.
    Purpose: Find a related parent element, such as a product table row.

56. matches()
    Definition: Checks whether an element matches a CSS selector.
    Purpose: Test an element against specific selector conditions.


PHASE 6 — FORMS AND VALIDATION
===============================

57. Reading Input Values
    Definition: Gets values entered into form fields.
    Purpose: Collect user information.

58. Handling Form Submission
    Definition: Handles the form submit event using JavaScript.
    Purpose: Process form data before sending or saving it.

59. Required-Field Validation
    Definition: Checks whether required fields contain values.
    Purpose: Prevent incomplete form submissions.

60. Checking Input Length and Format
    Definition: Checks input rules such as length and email format.
    Purpose: Ensure data follows expected rules.

61. Showing Validation Messages
    Definition: Displays errors or instructions near form fields.
    Purpose: Help users correct invalid information.

62. Resetting Forms
    Definition: Returns form controls to their initial values.
    Purpose: Clear the form after submission or when requested.

63. Preventing Default Form Submission
    Definition: Stops the browser's normal form submission.
    Purpose: Let JavaScript validate or submit data using fetch().

64. Safely Displaying User-Provided Text
    Definition: Displays user input as text instead of interpreting it as HTML.
    Purpose: Reduce HTML injection and XSS risks.


PHASE 7 — ADVANCED DOM CONCEPTS
===============================

65. DOMContentLoaded
    Definition: Event fired after HTML parsing and DOM construction.
    Purpose: Run JavaScript when the DOM is ready.

66. DOMContentLoaded vs load
    Definition: DOMContentLoaded waits for HTML parsing; load waits for
    dependent page resources to finish loading.
    Purpose: Choose the correct time to execute JavaScript.

67. dataset and data-* Attributes
    Definition: dataset provides access to custom data-* attributes.
    Purpose: Store small custom values such as product IDs on elements.

68. DocumentFragment
    Definition: A lightweight container for DOM nodes outside the active document.
    Purpose: Prepare multiple elements before inserting them into the page.

69. Creating Reusable Rendering Functions
    Definition: Functions that generate DOM elements from data.
    Purpose: Avoid repeating DOM creation code.

70. Rendering Arrays of Objects into Tables or Cards
    Definition: Converts JavaScript records into visible HTML elements.
    Purpose: Display database or API records dynamically.

71. Updating and Deleting Rendered Records
    Definition: Changes or removes elements representing data records.
    Purpose: Keep the interface synchronized with record changes.

72. DOM Performance and Avoiding Unnecessary Updates
    Definition: Reducing unnecessary DOM operations and rendering.
    Purpose: Improve webpage responsiveness.

73. Basic Accessibility When Changing the DOM
    Definition: Making dynamic webpage changes usable with keyboards
    and assistive technologies.
    Purpose: Build accessible interfaces.

IMPORTANT SECURITY NOTES
=========================

1. Use textContent for plain user-provided text.
2. Never insert untrusted user input directly into innerHTML.
3. Frontend validation is not a security boundary.
4. Flask must validate submitted data again on the server.
5. Never trust data simply because it came from your own webpage.
